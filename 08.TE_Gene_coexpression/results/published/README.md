# Published outputs

This folder contains selected small outputs from the 1,000-resample Figure 4
analysis. They are included so the headline result can be inspected without
downloading the large expression matrices.

| File | Description |
| --- | --- |
| `Figure4AB_1000resamples.pdf` | Publication-quality combined figure |
| `Figure4AB_1000resamples.png` | GitHub preview image |
| `figure4_AB_1000resamples_summary_stats.tsv` | Observed statistics and empirical P values |
| `figure4_AB_1000resamples_null_distribution.tsv` | Valid statistics from each background resample |
| `figure4_AB_1000resamples_sampling_results.rds` | Full R sampling object |
| `figure4_AB_1000resamples_summary_stats.rds` | R summary object |

The TSV files use tab delimiters despite retaining the source analysis's base
filename.
